# 🏋️ Gym Management System

A modern Gym Management Android application built with **Flutter** and **Supabase** to simplify gym operations. The system helps gym owners manage members, memberships, payments, expenses, reports, and renewal reminders from a single application.

## ✨ Features

* 📊 Dashboard with business insights
* 👥 Member Management (Add, Edit, Delete, Search)
* 📅 Membership Plans & Renewals
* 💳 Payment Tracking
* 💰 Expense Management
* 📈 Revenue, Expense & Profit Reports
* 📄 PDF Report Export
* 💬 One-Tap WhatsApp Renewal Reminder
* 🖼️ Member Profile Photos
* 🌙 Dark Mode Support
* ☁️ Cloud Database with Supabase

## 🛠️ Tech Stack

* **Frontend:** Flutter
* **Backend:** Supabase
* **Database:** PostgreSQL
* **Architecture:** MVVM + Clean Architecture
* **State Management:** Riverpod

## 📱 Target Platform

* Android (APK Distribution)
